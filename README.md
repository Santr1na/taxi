# FareLook — taxi-site

Современный лендинг для Android-приложения, которое помогает водителям Яндекс Про заранее узнавать ориентировочную стоимость поступающих заказов.

## Стек

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Framer Motion
- Lucide Icons

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3021](http://localhost:3021).

## Сборка

```bash
npm run build
npm start
```

## Структура

- `src/app/` — страницы и глобальные стили
- `src/components/` — секции лендинга (Hero, Benefits, FAQ и др.)
